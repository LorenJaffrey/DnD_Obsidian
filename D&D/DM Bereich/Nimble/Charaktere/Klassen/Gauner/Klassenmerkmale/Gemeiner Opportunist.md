# `=this.file.name`
Einmal pro [[Zug]] wenn du ein abgelenktes Ziel mit einem [[Nahkampfangriff]] triffst, darfst du den Trefferwurf auf einen beliebigen Wert ändern.
Dies kann einen  [[Kritische Treffer|Kritischen Treffer]] verursachen.

> [!tip]- Ablenkung  
> Ein Ziel ist abgelenkt, wenn es an einen Verbündeten angrenzt, von einem Verbündeten [[verspottet]] ist oder dich nicht sehen kann.
