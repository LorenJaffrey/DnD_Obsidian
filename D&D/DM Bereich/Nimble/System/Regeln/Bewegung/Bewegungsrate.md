# `=this.file.name`
Die Bewegungsgrate wird meist durch die [[Spezies]] festgelegt und beträgt in den meisten Fällen 9m (6 Kästchen) pro [[Zug]].
Sie bestimmt wie weit sich eine Kreatur im Kampf pro Runde bewegen kann.
Eine Kreatur kann auch eine eigene Bewegungsrate für  bestimmte Fortbewegungsarten wie [[Schwimmen]], [[Fliegen]], [[Graben]], etc. besitzen.
